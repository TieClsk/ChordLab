# 产品愿景 / Vision

**ChordLab**：看得见、听得到、能拆解的和弦学习与创作工具。在钢琴上弹出和弦，看它在歌曲里怎么走，把自己的音乐丢进去分析规律，最后用它来编曲。

## 已确认的产品决定（2026-11-15，PO 答复）

| 问题 | 决定 |
| --- | --- |
| 目标用户 | 两者兼顾：入门者通过教程学习；创作者用来做和弦创作、扒曲等 |
| 商用 | 主要本地使用，不涉及商业内容 → 可使用非商用许可的模型与数据（madmom、Chordonomicon） |
| 平台 | 最终兼顾电脑与移动端；**第一版聚焦电脑**（桌面应用优先，Web 版次之） |
| MIDI 键盘 | 暂无；后期可能需要 MIDI 输入，现在不做，但引擎接口预留 |
| 语言 | **中英双语**，所有界面文本从第一天起走国际化 |
| 编曲 | 后期纳入：MIDI 编写、鼓编写、合成器、采样导入编辑、混音、音频导出 |
| 技术路线 | B 路线：Rust 音频内核，原生 + WASM 双目标（ADR-0001） |

## 成功指标（MVP）

| 指标 | 目标 |
| --- | --- |
| 点击琴键到出声 | 主观无感（桌面 < 20 ms 端到端） |
| 和弦识别准确率（真实流行歌曲，maj/min） | ≥ 70% |
| 4 分钟歌曲快速分析耗时 | < 10 s |
| 新用户首次“听懂一个和弦进行” | < 5 分钟 |
